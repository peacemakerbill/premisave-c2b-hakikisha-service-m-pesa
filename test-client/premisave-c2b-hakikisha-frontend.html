Provider API test console

Calls the service the way Safaricom does: exchange the Basic Auth credentials for a Bearer token, resolve a phone number to an account name, and inspect the accounts the sync job has stored.

Procedure

  1. Issue an access tokenUsername and password are the service's HAKIKISHA_USERNAME and HAKIKISHA_PASSWORD.
  2. Send a name lookupAn M-Pesa number and the shortcode return the account name, or the error Safaricom would see.
  3. Check the saved accountsThe Lookup column shows which stored accounts can be resolved, and why not.
