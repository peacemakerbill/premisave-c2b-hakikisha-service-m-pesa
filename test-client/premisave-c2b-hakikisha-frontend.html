Drive the C2B Hakikisha provider API from one screen.

This is the provider side of Safaricom's C2B Hakikisha API — the service Safaricom itself calls to resolve an account name before a customer pays. There is no end-user account here: step one is the same Basic-Auth → Bearer token exchange Safaricom performs.

1
Generate an access tokenBasic Auth against HAKIKISHA_USERNAME / HAKIKISHA_PASSWORD, exactly like Safaricom's own client-credentials call.
2
Run a name lookupPOST an M-Pesa phone number and shortcode, get back the account name — or the same errors Safaricom would see.
3
Browse the synced directorySee exactly what the wallet-service sync job has saved, to pick a real phone number to test against.

Base URL & defaults

Stored only in this browser (localStorage). Nothing is sent anywhere else.
Use the same host and port as base_url_c2b_hakikisha in your Postman environment. The service's SERVER_PORT defaults to 8090 if you have not set it in .env. A browser also needs the service to allow cross-origin calls (CORS_ALLOWED_ORIGINS, default *), which Postman does not need.
